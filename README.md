# VOB SAS - Sistema de Gestão

Plataforma Multi-Tenant SaaS (Software as a Service) desenvolvida para o gerenciamento de múltiplos lojistas e comércios físicos.

## Stack Tecnológica

O projeto é construído utilizando ferramentas modernas e robustas do ecossistema PHP e Javascript:

- **Backend:** Laravel 11.x (PHP 8.3)
- **Frontend:** Vue.js 3 com Inertia.js
- **Estilização:** Tailwind CSS
- **Banco de Dados:** PostgreSQL
- **Ambiente de Desenvolvimento:** Docker (Laravel Sail)
